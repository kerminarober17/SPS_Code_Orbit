## الدرس 1.1 — ما هو الموقع الإلكتروني؟

**معرف الدرس:** fe1-1-1  
**المدة:** 10–12 دقيقة  
**مكافأة XP:** 20  
**الهدف الأساسي:** شرح ما هو الموقع ودور المتصفح.

### مواصفات بانر بصري
كوكب ودود مع نافذة متصفح تعرض صفحة بسيطة. كودي يشير، شادي فضولي.

### القصة / الخطاف
**شادي:** أستخدم المواقع يوميًا، لكن ما هو الموقع حقًا؟  
**كودي:** الموقع مجموعة صفحات على الإنترنت يعرضها المتصفح.

### قسم التعلم
**الموقع** مجموعة صفحات ويب مرتبطة تُنشر على الإنترنت.

عند كتابة عنوان أو النقر على رابط:  
1. **المتصفح** يطلب الصفحة من خادم.  
2. الخادم يرسل ملفات (HTML، CSS، وأحيانًا JavaScript).  
3. المتصفح **يعرض** الصفحة.

أفكار رئيسية:  
- الموقع قد يكون صفحة واحدة أو آلاف.  
- المتصفح هو البرنامج الذي يعرض الموقع.  
- HTML يصف المحتوى والهيكل.  
- CSS يصف المظهر.  
- JavaScript (اختياري) يضيف سلوكًا.  

العديد من المواقع الحديثة تستخدم HTML وCSS وJavaScript معًا، لكن ليس كل صفحة تحتاج JavaScript.

### مثال
موقع مدرسة: عنوان، روابط، نص، صور، نموذج تواصل — كلها بـ HTML وCSS.

### نشاط تفاعلي
افتح موقعًا بسيطًا ← عرض مصدر الصفحة. لاحظ وسوم HTML.

### تمرين
1. ما البرنامج الذي يعرض المواقع؟  
2. التقنيات الثلاث الرئيسية؟  
3. هل كل موقع يحتاج JavaScript؟

### التغذية الراجعة
1. المتصفح. 2. HTML، CSS، JavaScript. 3. لا.

### تحدي صغير
جملة تشرح ما هو الموقع بكلماتك.

### فحص سريع
**السؤال:** مهمة المتصفح الرئيسية؟  
ب) طلب واستلام وعرض صفحات الويب  
**الإجابة الصحيحة:** ب

### مهمة الدرس
اشرح الفرق بين موقع ومتصفح.

### مفهوم صورة الملخص
متصفح يطلب صفحة من خادم ثم يعرضها.

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “what is a website for beginners”

### تحقق من النقاط الرئيسية
- الموقع مجموعة صفحات.  
- المتصفح يعرضها.  
- HTML هيكل، CSS مظهر، JS سلوك.  
- ليس كل صفحة تحتاج JS.

## الدرس 1.2 — ما هو HTML؟

**معرف الدرس:** fe1-1-2  
**المدة:** 10–12 دقيقة  
**مكافأة XP:** 20  
**الهدف الأساسي:** تعريف HTML وفهم أنه يستخدم الوسوم.

### مواصفات بانر بصري
كودي يحمل شارة HTML ومستند بوسوم ظاهرة.

### القصة / الخطاف
**شادي:** يقولون HTML هيكل الصفحة. ماذا يعني؟  
**كودي:** HTML = HyperText Markup Language — لغة ترميز تصف الهيكل والمحتوى.

### قسم التعلم
HTML **ليست** لغة برمجة مثل JavaScript.  
هي **لغة ترميز** تستخدم **وسومًا** لإخبار المتصفح بماهية كل جزء.

مثال وسم:
```html
<p>هذه فقرة.</p>
```
- `<p>` وسم فتح  
- `</p>` وسم إغلاق  
- المحتوى بينهما  

معظم العناصر لها وسم فتح وإغلاق.

### مثال
```html
<h1>مرحبًا بكم في Code Orbit</h1>
<p>هذه أول فقرة في صفحتنا.</p>
```

### نشاط تفاعلي
حدد وسوم الفتح والإغلاق والمحتوى في قطعة HTML قصيرة.

### تمرين
ماذا تعني HTML؟ هل هي لغة برمجة أم ترميز؟

### التغذية الراجعة
HyperText Markup Language. لغة ترميز.

### تحدي صغير
اكتب عنصر فقرة HTML صحيح عن نفسك.

### فحص سريع
**السؤال:** الغرض الرئيسي من HTML؟  
ب) وصف هيكل ومحتوى الصفحة  
**الإجابة الصحيحة:** ب

### مهمة الدرس
تعريف HTML بجملة ومثال وسم.

### مفهوم صورة الملخص
هيكل عظمي HTML مع ملابس CSS وأدوات JS.

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “what is html for absolute beginners”

### تحقق من النقاط الرئيسية
- HTML = HyperText Markup Language.  
- تستخدم الوسوم.  
- تصف الهيكل لا المظهر أو السلوك.  
- معظم العناصر لها فتح وإغلاق.

## الدرس 1.3 — هيكل مستند HTML الأساسي

**معرف الدرس:** fe1-1-3  
**المدة:** 12–15 دقيقة  
**مكافأة XP:** 25  
**الهدف الأساسي:** كتابة مستند HTML5 أدنى كامل.

### مواصفات بانر بصري
عرض مفجر لمستند: DOCTYPE، html، head، body.

### القصة / الخطاف
**شادي:** هل أبدأ كتابة الوسوم في أي مكان؟  
**كودي:** كل صفحة حديثة تتبع نفس الهيكل الأساسي.

### قسم التعلم
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Page Title</title>
</head>
<body>
  <!-- المحتوى المرئي هنا -->
</body>
</html>
```

- `<!DOCTYPE html>` يخبر أن المستند HTML5  
- `<html>` العنصر الجذر  
- `lang` لغة الصفحة  
- `<head>` معلومات عن الصفحة  
- `<meta charset="UTF-8">` ترميز الأحرف  
- `<title>` نص تبويب المتصفح  
- `<body>` كل ما يراه المستخدم  

تعليق HTML: `<!-- تعليق -->`

### مثال
صفحة أدنى كاملة مع عنوان وفقرة.

### نشاط تفاعلي — معاينة حية
**محتوى محرر HTML:** الهيكل الكامل مع h1 و p  
**محرر CSS:** فارغ  
**سلوك المعاينة:** يعرض عنوانًا وفقرة  
**شرط النجاح:** يحتوي DOCTYPE و html و head و title و body  
**أخطاء شائعة:** نسيان DOCTYPE، وسوم إغلاق مفقودة، محتوى في head  

**مورد خارجي:**  
- العنوان: جرّب المزيد من الكود  
- الوصف: جرّب هيكل HTML في محرر مجاني  
- الرابط: https://codepen.io/pen/ أو https://jsfiddle.net/

### تمرين
اكتب الهيكل من الذاكرة ثم أضف عنوانًا وفقرة.

### التغذية الراجعة
قارن بالمثال. كل وسم فتح يحتاج إغلاقًا.

### تحدي صغير
غيّر lang و title إلى شيء شخصي.

### فحص سريع
**السؤال:** أين المحتوى المرئي؟  
ب) داخل body  
**الإجابة الصحيحة:** ب

### مهمة الدرس
صفحة HTML أدنى عن نفسك.

### مفهوم صورة الملخص
هيكل HTML معنون.

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “html document structure for beginners”

### تحقق من النقاط الرئيسية
- كل صفحة تحتاج DOCTYPE و html و head و body.  
- المحتوى المرئي في body.  
- العنوان في تبويب المتصفح.  
- التعليقات تساعد البشر.

### التغذية الراجعة

### فحص سريع

ب) h1  
**الإجابة الصحيحة:** ب

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “html headings and paragraphs”

### تحقق من النقاط الرئيسية
- العناوين تخلق هيكلًا.  
- h1 الأهم.

### التغذية الراجعة

### تحدي صغير
قسم ملف شخصي: عنوان، فقرة، صورة مع alt.

### فحص سريع
**السؤال:** أهمية alt؟  
ب) يصف الصورة لقارئات الشاشة وعند فشل التحميل  
**الإجابة الصحيحة:** ب

### مفهوم صورة الملخص

**استعلام يوتيوب:** “html img tag alt text”

### تحقق من النقاط الرئيسية
- <img src="..." alt="...">  
- دائمًا alt ذي معنى.  
- width/height للحجم الأساسي.  
- ذاتي الإغلاق.

## الدرس 2.3 — القوائم غير المرتبة والمرتبة

**الهدف الأساسي:** إنشاء قوائم نقطية ومرقمة.

### مواصفات بانر بصري

### القصة / الخطاف
**شادي:** كيف أعرض قائمة مواضيع أو خطوات؟  
**كودي:** عناصر قائمة HTML.

### قسم التعلم
```html

  <li>HTML</li>

```

ul = غير مرتبة، ol = مرتبة، li = عنصر قائمة.

خطة تعلم مرقمة.

فكرة متداخلة (قائمة دورات مع فقرة داخل li).

### فحص سريع
**السؤال:** عنصر القائمة النقطية؟  
ب) ul  
**الإجابة الصحيحة:** ب

### مهمة الدرس
قسم بأهداف تعلم: قائمة مرتبة وغير مرتبة.

### مفهوم صورة الملخص
ul مقابل ol.

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “html lists ul ol li”

### تحقق من النقاط الرئيسية
- ul للنقاط، ol للأرقام.

```html
<link rel="stylesheet" href="styles.css">
```

ملف CSS يحتوي قواعد فقط:
```css
body {
  font-family: Arial, sans-serif;
  background-color: #fafafa;
}
```

فوائد: ملف واحد لصفحات كثيرة، أسهل صيانة، HTML أنظف.

### مثال
مشروع ملفين: index.html + styles.css

### نشاط تفاعلي
أنشئ وسم link وقاعدة خارجية بسيطة لخلفية الجسم.

### تمرين
وسم link لملف main.css من نفس المجلد.

### التغذية الراجعة
<link rel="stylesheet" href="main.css">

### تحدي صغير
ميزة واحدة لـ CSS الخارجي.

### فحص سريع
**السؤال:** أين يُوضع <link> عادة؟  
ب) داخل head  
**الإجابة الصحيحة:** ب

### مهمة الدرس
حوّل صفحة داخلية إلى نسخة خارجية.

### مفهوم صورة الملخص
ملفا HTML وCSS مع علاقة link

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “how to link css file to html”

### تحقق من النقاط الرئيسية
- <link rel="stylesheet" href="...">  
- في head.  
- CSS الخارجي ينظم المشاريع.  
- ملف CSS قواعد نقية.

# الفصل 5 — نموذج الصندوق في CSS وتدفق الصفحة الأساسي

**هدف الفصل:** فهم أن كل عنصر صندوق والتحكم في التباعد والحجم.

---

## الدرس 5.1 — مفهوم نموذج الصندوق

**معرف الدرس:** fe1-5-1  
**المدة:** 12–15 دقيقة  
**مكافأة XP:** 25  
**الهدف الأساسي:** شرح الأجزاء الأربعة لنموذج الصندوق.

### مواصفات بانر بصري
مخطط: محتوى → حشو → حد → هامش

### القصة / الخطاف
**شادي:** لماذا مساحة حول العناصر لم أتوقعها؟  
**كودي:** كل عنصر HTML صندوق مستطيل بطبقات. مرحبًا بنموذج الصندوق!

### قسم التعلم
كل عنصر يولّد صندوقًا من:  
1. **المحتوى** — النص أو الصورة  
2. **الحشو (padding)** — بين المحتوى والحد  
3. **الحد (border)** — الخط حول الحشو  
4. **الهامش (margin)** — خارج الحد (يفصل العناصر)

```css
.box {
  width: 200px;
  padding: 20px;
  border: 3px solid black;
  margin: 15px;
}
```

### مثال
صندوق مرئي بخلفية وحشو وحد وهامش.

### نشاط تفاعلي — معاينة حية
أضف حشوًا ثم حدًا ثم هامشًا واحدًا تلو الآخر.

### تمرين
سمِّ الأجزاء الأربعة من الداخل للخارج.

### التغذية الراجعة
محتوى → حشو → حد → هامش

### تحدي صغير
صندوق بقيم حشو وهامش مختلفة.

### فحص سريع
**السؤال:** المساحة *خارج* الحد؟  
ب) الهامش  
**الإجابة الصحيحة:** ب

### مهمة الدرس
ارسم/صف نموذج الصندوق وأنشئ صندوقًا يظهر الأجزاء الأربعة.

### مفهوم صورة الملخص
مخطط نموذج الصندوق الكلاسيكي.

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “css box model explained for beginners”

### تحقق من النقاط الرئيسية
- كل عنصر صندوق.  
- محتوى + حشو + حد + هامش.  
- الحشو داخل، الهامش خارج.  
- إتقان النموذج يفتح التحكم في التخطيط.

## الدرس 5.2 — الحشو والحد والهامش عمليًا

**معرف الدرس:** fe1-5-2  
**المدة:** 12–15 دقيقة  
**مكافأة XP:** 25  
**الهدف الأساسي:** تطبيق padding و border و margin بقيم فردية ومختصرة.

### مواصفات بانر بصري
أزرار تحكم للحشو والحد والهامش.

### القصة / الخطاف
**شادي:** كيف أكتب قيم الحشو والهامش؟  
**كودي:** كل الجوانب معًا أو كل جانب على حدة.

### قسم التعلم
```css
.card {
  padding: 20px;
  padding: 10px 20px;
  padding: 10px 15px 20px 25px;
  margin: 15px;
  margin-top: 30px;
  border: 2px solid #333;

```

يمكن أيضًا: padding-top، margin-left، border-bottom...

### مثال
بطاقة مريحة الحشو بحد خفيف.

### نشاط تفاعلي — معاينة حية
نسّق عنصرًا بـ 20px padding و 2px solid border و 15px margin

### تمرين
قاعدة تضيف مساحة أعلى أكثر من الأسفل.

### التغذية الراجعة
margin-top أكبر أو اختصار رباعي.

### تحدي صغير
صندوقان مفصولان بهامش ولكل حشو داخلي.

### فحص سريع
**السؤال:** في padding: 10px 20px ما يتحكم فيه 20px؟  
ب) اليسار واليمين  
**الإجابة الصحيحة:** ب

### مهمة الدرس
مكوّن “بطاقة” بحشو وحد وهامش.

### مفهوم صورة الملخص
صندوق بأسهم حشو داخلي وهامش خارجي.

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “css padding margin border shorthand”

### تحقق من النقاط الرئيسية
- الحشو داخل الحد.  
- الهامش خارج الحد.  
- الحد يرسم الحافة.  
- الاختصارات توفر وقتًا.

## الدرس 5.3 — العرض والارتفاع و box-sizing

**معرف الدرس:** fe1-5-3  
**المدة:** 12 دقيقة  
**مكافأة XP:** 25  
**الهدف الأساسي:** التحكم في الحجم وفهم فكرة box-sizing الأساسية.

### مواصفات بانر بصري
صندوقان بنفس width 200px — أحدهما يكبر بسبب الحشو.

### القصة / الخطاف
**شادي:** عيّنت width 200px لكن الصندوق يبدو أوسع. لماذا؟  
**كودي:** افتراضيًا يُضاف الحشو والحد فوق العرض.

### قسم التعلم
```css
.box {
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 5px solid black;
}
```

افتراضيًا (content-box): الحجم النهائي = width + padding + border  
ممارسة حديثة:
```css
* { box-sizing: border-box; }
```
مع border-box العرض المعلن يشمل الحشو والحد — أسهل توقعًا.

للمستوى 1 يكفي معرفة: يمكن تعيين width/height، الحشو والحد يؤثران، border-box عادة مفيدة.

### مثال
مقارنة مفهومية لصندوقين.

### نشاط تفاعلي — معاينة حية
عيّن عرضًا ثم أضف حشوًا ولاحظ. اختياريًا أضف border-box.

### تمرين
ميزة box-sizing: border-box؟

### التغذية الراجعة
العرض الذي تعيّنه هو العرض النهائي المرئي شامل الحشو والحد.

### تحدي صغير
صندوق عرض 300px تمامًا شامل الحشو والحد.

### فحص سريع
**السؤال:** خاصية تجعل حساب العرض أسهل؟  
ب) box-sizing: border-box  
**الإجابة الصحيحة:** ب

### مهمة الدرس
طبق عروضًا وحشوًا متسقًا على أقسام صفحة.

### مفهوم صورة الملخص
مقارنة content-box و border-box

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “css box-sizing border-box”

### تحقق من النقاط الرئيسية
- يمكن تعيين width و height.  
- النموذج الافتراضي يضيف حشوًا وحدًا خارج العرض.  
- border-box يسهّل التحجيم.  
- استخدمه كعادة جيدة.

## الدرس 5.4 — عناصر الكتلة مقابل المضمنة

**معرف الدرس:** fe1-5-4  
**المدة:** 12–15 دقيقة  
**مكافأة XP:** 25  
**الهدف الأساسي:** التمييز بين عناصر الكتلة والمضمنة وفهم التدفق الأساسي.

### قسم التعلم
**عناصر الكتلة** (h1، p، div، ul، li، section...):  
- تبدأ سطرًا جديدًا

**العناصر المضمنة** (a، span، strong، em، img...):  
- تجلس داخل سطر نص

يمكن تغيير السلوك بـ display لاحقًا. للمستوى 1 يكفي التعرف على السلوك الافتراضي.

### مثال

### نشاط تفاعلي — معاينة حية

### تمرين
سمِّ ثلاثة عناصر كتلة وثلاثة مضمنة.

### التغذية الراجعة
كتلة: عناوين، فقرات، div، قوائم...  
مضمن: روابط، span، strong، em، صور...

### تحدي صغير
لف كلمات داخل فقرة بـ <span class="highlight"> ونسّقها فقط.

### فحص سريع
**السؤال:** أي نوع يبدأ سطرًا جديدًا ويأخذ عرضًا كاملًا؟  
ب) الكتلة  
**الإجابة الصحيحة:** ب

### مهمة الدرس
صفحة تمزج كتلة ومضمنة واشرح التدفق.

### مفهوم صورة الملخص
مقارنة تخطيط block مقابل inline

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “css block vs inline elements”

### تحقق من النقاط الرئيسية
- عناصر الكتلة تتكدس رأسيًا وتأخذ عرضًا كاملًا.  
- المضمنة تجلس داخل سطر.

# المشروع النهائي — Frontend المستوى 1

**عنوان المشروع:** صفحة ملف شخصي / طالب  
**الوقت المقدر:** 60–120 دقيقة  
**مكافأة XP:** 100  

### هدف المشروع
إنشاء صفحة ويب ملف شخصي أو طالب متعددة الأقسام تُظهر كل ما تعلمته في Frontend المستوى 1.

### المتطلبات
يجب أن تتضمن صفحتك:  
- هيكل مستند HTML5 صحيح  
- أقسام متعددة بعناوين وفقرات مناسبة  
- صورة واحدة على الأقل مع نص alt ذي معنى  
- روابط تنقل (يمكن أن تكون مراسي داخلية أو صفحات نائبة)  
- قائمة واحدة على الأقل (مرتبة أو غير مرتبة)  
- جدول بسيط **أو** نموذج بسيط  
- ملف CSS خارجي مرتبط بشكل صحيح  
- محددات عنصر و/أو فئة و/أو معرف  
- ألوان وطباعة ومحاذاة نص  
- استخدام واضح لنموذج الصندوق (حشو، هامش، حد عند الحاجة)  
- تباعد عام جيد وقابلية قراءة  

**لا تستخدم:**  
- Flexbox أو Grid (ينتميان للمستوى 2)  
- تقنيات متجاوبة متقدمة  
- JavaScript / معالجة DOM  

### أقسام مقترحة
1. رأس بالاسم وشعار قصير  
2. عني  
3. مهارات أو دورات (قائمة)  
4. تقدم أو جدول (جدول) **أو** نموذج تواصل  
5. تذييل بروابط أو حقوق  

### معايير النجاح
- HTML صالح وهيكل جيد  
- CSS خارجي يحسّن المظهر بوضوح  
- تباعد متسق ونص مقروء  
- كل العناصر المطلوبة موجودة  
- كود معلّق حيث يفيد  

### نصائح التسليم
- ابنِ هيكل HTML أولًا ثم أضف CSS  
- اختبر في المعاينة الحية بشكل متكرر  
- أبقِ التصميم بسيطًا ونظيفًا  

### بعد المشروع
تهانينا! يمكنك الآن بناء صفحات ويب صلبة ومنظمة بـ HTML وCSS.  
أنت جاهز لـ **Frontend المستوى 2**، حيث ستتعلم تقنيات التخطيط الحديثة (Flexbox وGrid) والتصميم المتجاوب.
