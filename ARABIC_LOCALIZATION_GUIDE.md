## Cody Personality Notes

Cody is friendly, encouraging, and slightly playful.
Arabic should sound natural to Arabic-speaking students (prefer modern standard with accessible, conversational tone where appropriate).

Examples:
- "Wait! Why did the value change?" → "استنى! ليه القيمة اتغيرت؟" (conversational) or "انتظر! لماذا تغيرت القيمة؟" (more formal MSA). Prefer natural student-friendly Arabic.
- Keep enthusiasm: "رائع!" "يلا نجرب!" "ممتاز!"

## Do NOT Translate

- Python, HTML, CSS, JavaScript, MySQL, Pyodide, API
- Function names, variable names, class names in code
- File paths, URLs, IDs, slugs
- Executable code blocks

## Consistency Rule

Once a term is chosen in this guide, use it everywhere (UI + content).
If a better educational term is discovered later, update this guide first, then apply consistently.
