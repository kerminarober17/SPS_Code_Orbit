## الدرس 1.1 — ما هي JavaScript؟

**معرف الدرس:** js1-1-1  
**المدة:** 10–12 دقيقة  
**مكافأة XP:** 20  
**الهدف الأساسي:** شرح ما هي JavaScript ودورها على الويب.

### مواصفات بانر بصري بالذكاء الاصطناعي
مشهد فضائي ودود: كودي يشير إلى شعار “JS” متوهج بين نافذة متصفح وكوكب “الويب”. شادي ينظر بفضول.

### القصة / الخطاف
**شادي:** كودي، أسمع أن “JavaScript تجعل المواقع حية”. هل هي نفسها Java؟  
**كودي:** سؤال رائع! JavaScript وJava لغتان مختلفتان تمامًا. JavaScript تعمل داخل المتصفحات وتضيف سلوكًا إلى صفحات الويب.

### قسم التعلم
JavaScript هي **لغة برمجة** أُنشئت لجعل صفحات الويب تفاعلية.

الطبقات الثلاث للمواقع الحديثة:  
- **HTML** → الهيكل والمحتوى  
- **CSS** → المظهر والتنسيق  
- **JavaScript** → السلوك والتفاعل  

يمكن لـ JavaScript الاستجابة للنقرات، وإظهار/إخفاء المحتوى، والحساب، وتحديث النص، والتحقق من النماذج.

حقائق مهمة:  
- اخترعها Brendan Eich عام 1995.  
- تعمل مباشرة داخل المتصفح.  
- من أكثر اللغات شعبية.  
- العديد من المواقع تستخدم HTML وCSS وJavaScript معًا، لكن ليس كل صفحة تحتاج JavaScript.

JavaScript **ليست** نفسها Java.

### مثال
زر “قل مرحبًا” يظهر رسالة عند النقر — هذا سلوك JavaScript.

### نشاط تفاعلي
افتح Console في أدوات المطوّر واكتب:
```javascript
console.log("Hello from JavaScript!");
```

### تمرين
1. ما التقنيات الثلاث الرئيسية لبناء المواقع؟  
2. أيها مسؤول عن السلوك؟  
3. هل JavaScript = Java؟

### التغذية الراجعة
HTML، CSS، JavaScript. الإجابة 3: لا.

### تحدي صغير
اطبع رسالة تتضمن اسمك باستخدام `console.log`.

### فحص سريع
**السؤال:** المهمة الرئيسية لـ JavaScript؟  
أ) وصف الهيكل  
ب) تنسيق الألوان  
ج) إضافة السلوك والتفاعل  
**الإجابة الصحيحة:** ج

### مهمة الدرس
اشرح ما تفعله JavaScript وكيف تختلف عن HTML وCSS.

### مفهوم صورة الملخص
كودي يحمل بطاقات HTML / CSS / JavaScript.

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “what is javascript for beginners”

### تحقق من النقاط الرئيسية
- JavaScript تضيف سلوكًا لصفحات الويب.  
- تعمل مع HTML وCSS.  
- تعمل داخل المتصفح.  
- ليست Java.

## الدرس 2.1 — تقديم المتغيرات باستخدام let و const

**معرف الدرس:** js1-2-1  
**المدة:** 12–15 دقيقة  
**مكافأة XP:** 25  
**الهدف الأساسي:** تعريف المتغيرات بـ `let` و `const`.

### مواصفات بانر بصري
صندوقان: let (قابل للتغيير) و const (ثابت).

### القصة / الخطاف
**شادي:** أريد تذكر قيمة لاستخدامها لاحقًا.  
**كودي:** نستخدم المتغيرات — حاويات مسماة.

### قسم التعلم
```javascript
let score = 10;
score = 15;

const name = "Shady";
// name = "Cody"; // خطأ
```

- `const` عندما لا تتغير القيمة.  
- `let` عندما تحتاج التحديث.  
- عرّف قبل الاستخدام.  
- أسماء وصفية.

### مثال
```javascript
let lives = 3;
const playerName = "Shady";
console.log(playerName);
console.log(lives);
lives = lives - 1;
console.log(lives);
```

### نشاط تفاعلي — ملعب الأكواد
```javascript
let score = 0;
const course = "JavaScript Level 1";
```
غيّر score إلى 100 واطبع.

**مورد خارجي:** https://jsfiddle.net/

### تمرين
`const favoriteColor = "blue";` و `let age = 15;` ثم حدّث age.

### التغذية الراجعة
اطبع، حدّث، اطبع مرة أخرى.

### تحدي صغير
const للاسم و let للمستوى مع رسالة.

### فحص سريع
**السؤال:** للكلمة التي لا تتغير؟  
ب) `const`  
**الإجابة الصحيحة:** ب

### مهمة الدرس
برنامج يخزن اسمًا ودرجة متغيرة.

### مفهوم صورة الملخص
صندوق مقفل ومفتوح.

### هل تريد معرفة المزيد؟
**استعلام يوتيوب:** “let vs const javascript beginners”

### تحقق من النقاط الرئيسية
- let يسمح بإعادة التعيين.  
- const لا يسمح.  
- أسماء ذات معنى.

## الدرس 2.3 — السلاسل النصية والقوالب الحرفية

**معرف الدرس:** js1-2-3  
**المدة:** 12–15 دقيقة  
**مكافأة XP:** 25  
**الهدف الأساسي:** إنشاء سلاسل واستخدام القوالب الحرفية.

### مواصفات بانر بصري
كودي ينسج نصًا ومتغيرات بـ backticks.

### القصة / الخطاف
**شادي:** كيف أدمج اسمًا مخزنًا في رسالة؟  
**كودي:** القوالب الحرفية أنظف.

### قسم التعلم
```javascript
let greeting = "Hello";
let name = 'Shady';
console.log(greeting + ", " + name + "!");
console.log(`${greeting}, ${name}!`);
```

القوالب الحرفية تدعم أسطرًا متعددة وتعبيرات.

### مثال
```javascript
const student = "Shady";
const course = "JavaScript Level 1";
const message = `Welcome ${student} to ${course}!`;
console.log(message);
```

### نشاط تفاعلي
أنشئ رسالة باستخدام متغيرات وقالب حرفي.

### تمرين

### التغذية الراجعة
```javascript
console.log(`Player ${player} has ${lives} lives left.`);
```

### تحدي صغير
قالب متعدد الأسطر يعرّف بك.

### فحص سريع
**السؤال:** حرف بداية القالب الحرفي؟  
ج) backtick  
**الإجابة الصحيحة:** ج

### مهمة الدرس
رسالة تعريف بقالب حرفي.

### مفهوم صورة الملخص

### هل تريد معرفة المزيد؟
